# 💜 MINHA VIDA — PWA

Primeiro módulo funcional: 📝 Pendências.

## Recursos já funcionais
- PWA instalável (`manifest.webmanifest`)
- Service worker e cache offline
- Dados persistentes localmente no aparelho via `localStorage`
- Adicionar, editar, concluir, reabrir e excluir pendências
- Prazo, categoria e observação
- Abiertas/concluídas
- Busca
- Interface mobile-first para iPhone

## Publicação
Pode ser hospedado em Vercel Hobby, GitHub Pages ou outro host HTTPS estático que aceite arquivos estáticos e service worker.
